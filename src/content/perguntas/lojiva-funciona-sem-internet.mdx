Essa é uma dúvida legítima, principalmente para lojas em regiões com internet instável. A resposta honesta é direta: **a Lojiva precisa de internet para funcionar**.

## Por que a Lojiva precisa de internet

A Lojiva é um sistema de gestão **em nuvem** (web). Isso significa que o [PDV](/recursos/pdv), o estoque, o financeiro e a emissão fiscal rodam a partir de servidores acessados pela internet — não há uma cópia completa do sistema instalada no computador da loja. Sem conexão, o sistema não consegue registrar novas vendas nem consultar dados em tempo real.

## Para quem isso importa

Essa limitação pesa mais para:

- Lojas em **regiões com internet instável** ou quedas frequentes;
- Operações de **feira, eventos ou pontos móveis** sem conexão garantida.

Para a maioria das lojas com internet fixa razoável, o funcionamento é contínuo.

## O trade-off por trás dessa escolha

Ser um sistema em nuvem é uma decisão de projeto com vantagens reais:

- Os **dados ficam seguros e centralizados** fora do computador da loja — se uma máquina quebra, nada se perde;
- Você **acessa de qualquer dispositivo e local** (útil para multi-loja e para acompanhar a loja de fora);
- O sistema fica **sempre atualizado**, sem instalar versão em cada computador.

O preço dessa escolha é a dependência de conexão. É um trade-off consciente, não um descuido.

## A alternativa prática

Para reduzir o risco de parada, a recomendação é ter uma **conexão de contingência** — por exemplo, um chip 4G/5G de backup que assuma se a internet principal cair. Isso mantém o balcão funcionando mesmo em quedas pontuais. Para cobranças com maquininha, veja como o [Smart TEF](/recursos/tef-e-maquininha) se integra ao PDV.

Se a estabilidade de internet no seu ponto é uma preocupação, [converse com a equipe da Lojiva](/precos) antes de decidir.
